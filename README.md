# 商审台 · 商品上架与资料审核

一个可直接运行和部署的商品资料提交、审核、驳回与状态追踪应用。项目面向电商运营场景，把“运营提交资料”和“审核人员给出结论”放在同一条可追溯流程中。

## 在线体验

- 在线演示：https://wforovz888.github.io/product-review-mvp/
- 项目仓库：https://github.com/WforovZ888/product-review-mvp

当前版本是纯前端应用，演示数据保存在浏览器 `localStorage`，无需服务器或数据库。

## 核心功能

- 工作台概览：商品总数、待审核、已通过、已驳回、可售库存。
- 商品资料：新建、编辑、图片上传、分类、价格、库存、供应商与详情说明。
- 完整度校验：提交前自动检查必填项、价格库存和资料长度。
- 审核工作台：查看待审商品、资料完整度、历史记录和提交时间。
- 审核结论：支持通过、驳回并记录原因，所有操作写入审计时间线。
- 状态追踪：草稿、待审核、已通过、已驳回四态清晰展示。
- 搜索筛选：按名称、编码、供应商和状态快速定位。
- 响应式界面：桌面、平板和手机上均可使用。
- 演示数据：首次打开自动生成，便于直接验收。

## 本地运行

无需安装依赖，使用任意静态文件服务器：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

直接双击 `index.html` 也能查看界面，但建议使用静态服务器，以保持模块加载行为与线上部署一致。

## 自动测试

```bash
node --test tests/state.test.mjs
```

测试覆盖数据校验、提交流转、驳回后修改重提、审核通过和统计逻辑。

## 审核流程

```text
草稿
  └─ 提交审核 → 待审核
                   ├─ 审核通过 → 已通过
                   └─ 审核驳回 → 已驳回
                                      └─ 修改后重新提交 → 待审核
```

待审核商品不可修改；已通过商品锁定，避免审核结论与展示内容不一致。

## 数据说明

- 本仓库不包含真实商品或个人信息。
- 浏览器数据仅保存在本机，不会上传到第三方。
- 清除浏览器网站数据会重置演示内容。
- 若要接入真实多人协作，可将 `state.js` 的业务规则迁移到服务端 API，并增加登录、权限和数据库。

## 部署到 GitHub Pages

1. 创建公开 GitHub 仓库。
2. 推送本项目全部文件。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)` 目录。
6. 保存后等待 GitHub 生成公开访问地址。
